# Roundtable MCP Manifest

Generated by `roundtable init` / `roundtable mcp inspect --write`.

Server: unix://.roundtable/mcp/roundtable.sock
Protocol: MCP-compatible local tool server

## Mandatory Rules

You are operating inside Roundtable.

You may inspect the repository read-only.

You must not directly modify repository files.

All changes must be submitted as patch proposals through MCP.

Before proposing a patch, you must claim every affected resource.

If a resource is claimed by another agent, do not touch it unless your role and task assignment permit review of that resource.

Roundtable state is authoritative. Your external CLI session memory is not authoritative.

## Startup / Resume Checklist

1. Call `table.get_state`.
2. Call `memory.query` for task-relevant history.
3. Call `task.get` for your assigned task.
4. Call `resource.claim_status` for any claims you believe you own.
5. Continue only after reconciling your memory with the table.

## Required Change Flow

1. Query table state.
2. Query memory if relevant.
3. Search/read repo.
4. Claim affected resources.
5. Prepare unified diff.
6. Submit proposal through `proposal.create`.
7. Wait for review/vote/decision.
8. Revise only if requested.
9. Release claims when done.
