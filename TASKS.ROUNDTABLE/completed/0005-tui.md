# 0005 Bubble Tea TUI

## Goal

Build the primary Roundtable TUI with four panes.

## Layout

- top-left: Live Table
- top-right: Watch Feed
- bottom-left: Human Command Terminal
- bottom-right: Inspector

## Acceptance criteria

- TUI uses Bubble Tea and Bubbles components.
- Live Table displays tasks, claims, proposals, consensus state, and blockers.
- Watch Feed streams events.
- Human Command Terminal accepts commands.
- Inspector changes based on selected task/proposal/claim/agent/memory/test/security item.

## Completion evidence

- Live Table shows indexed raw vote tallies and blocked task details without treating counts as governance verdicts.
- Watch Feed streams in-process events and reconciles via periodic database refresh.
- Human Command Terminal accepts bounded Roundtable commands and displays asynchronous execution with a Bubbles spinner.
- Inspector cycles forward/backward through task, proposal, claim, agent, memory, test, and security records; selection survives refresh and clears when the record disappears.
- Regression coverage includes all selectable record kinds, selector wrapping, refresh behavior, multiline value normalization, and spinner ticks.
- `go test ./...`, `go test -race ./...`, `go build ./...`, `go vet ./...`, and `git diff --check` pass.
- Independent review findings were addressed; final review found no actionable findings.
