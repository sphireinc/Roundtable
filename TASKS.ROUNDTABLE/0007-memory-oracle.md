# 0007 Memory Oracle

## Goal

Implement persistent team memory and a Memory Oracle agent.

## Scope

- memory_entries table
- memory query MCP tool
- memory record MCP tool
- decision summarization
- stale memory marking
- Oracle warnings when proposals contradict durable memory

## Acceptance criteria

- Agents can query memory.
- Decisions can become durable memory entries.
- Oracle can summarize task history.
- Oracle can flag contradiction with prior decisions.

## Risk

Normal
